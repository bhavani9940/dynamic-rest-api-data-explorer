# Dynamic JavaScript DOM Logic & RESTful API Client

## Task 5

This project demonstrates a modern JavaScript ES6+ REST API client.

### Features

- REST API integration
- Fetch API
- Async/Await
- Dynamic DOM manipulation
- Search filtering
- User filtering
- Client-side state management
- Loading state
- Error handling
- Refresh data functionality
- Responsive CSS design

### API Used

JSONPlaceholder Posts API:

https://jsonplaceholder.typicode.com/posts

### Files

- index.html
- style.css
- script.js
- README.md

### How to Run

Open `index.html` in a modern web browser.

An internet connection is required because the application
fetches live data from the REST API.
